# 🔐 Password Strength Checker

A beginner-friendly Python application that evaluates password strength based on five predefined security criteria.

## 📌 Overview

This project analyzes a password and assigns it a strength classification based on its characteristics.

It also identifies missing requirements and provides suggestions to help users improve their passwords.

## ✨ Features

- Checks whether the password contains at least 8 characters.
- Detects uppercase letters.
- Detects lowercase letters.
- Detects numbers.
- Detects special characters.
- Calculates a score based on the five criteria.
- Classifies passwords into five categories:
  - Very Strong
  - Strong
  - Moderate
  - Weak
  - Very Weak
- Provides feedback explaining which requirements are missing.
- Supports repeated password evaluation.
- Allows users to terminate the program by entering `x`.

2. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

3. Navigate to the project directory.
4. Run the program:

   ```bash
   python password.py
   ```

## 📊 Evaluation Criteria

| Requirement | Condition |
|---|---|
| Length | At least 8 characters |
| Uppercase | At least one uppercase letter |
| Lowercase | At least one lowercase letter |
| Numbers | At least one digit |
| Special characters | At least one supported special character |

## ⚠️ Disclaimer

This is an educational project designed to practice Python programming and basic password evaluation.

Its scoring system is based on predefined criteria and does not represent a comprehensive assessment of real-world password security.
